# 0.1.0 공개 프리뷰 릴리스 초안

현재 상태는 **초안 소스 프리뷰 준비 중**입니다. 콘텐츠 버전 `0.1.0-draft.12`와 퀴즈 문구는 독립적인 사람 검토 전이므로 정식 안전 안내나 HACS 안정 릴리스로 취급하지 않습니다. 통합 manifest 버전 `0.1.0`과 안내 콘텐츠 버전은 별개입니다. 최신 구현·검증 상태는 [현재 작업 상태](current-status.ko.md)에 기록합니다.

## 제공 파일

- `custom_components/kr_survival_kit/` · HA Core 2026.11.1 운영 설치 이력이 있는 로컬 재고 통합. 이번 후보는 카탈로그 56개(선택 물품 45개)와 구매 단위별 기한 점검을 포함하며 격리 HA에서 검증했습니다.
- `kr-survival-kit-a4.pdf` · 경보별 첫 행동, 대피 후 점검, 가족 기록칸을 담은 A4 단면 한 장.
- `kr-survival-kit-offline.html` · 시간대별 대응, 전환표, 4인 가구 3일 준비량과 품목별 근거를 인터넷 없이 보는 파일. 인쇄하면 한 장 행동 카드가 나옵니다.
- `dashboard.yaml` · 비축 관리와 상황 안내를 각각 전체 폭 카드로 제공하는 대시보드 원시 설정. 안내 보기의 파일 버튼은 `/local/kr-survival-kit-a4.pdf`와 `/local/kr-survival-kit-offline.html`을 엽니다.
- `kr-survival-kit-card.js` · 완비한 품목의 그림이 나타나는 2D 비축 화면, 시간 표시, 선택형 날씨를 제공하는 카드 리소스. 통합 폴더에도 포함됩니다.

## 검증 기록과 공개 전 남은 작업

- P5의 격리 HA 시험과 운영 HA의 설치·업데이트 결과는 [P5 검증 기록](p5-validation.md)과 [NRGNC 운영 검증](../README.md#nrgnc-운영-검증-2026-11-11)에 기록했습니다. 실제 운영 재고는 수정하지 않았습니다.
- 생성 파일과 운영 HTTP 응답의 해시, HTML·PDF 안내 버전 일치 및 A4 한 쪽은 확인했습니다. 실물 인쇄에서 한글 글꼴·페이지 잘림·필기 공간을 다시 확인해야 합니다.
- 2026년 행정안전부 안내와 문장별 대조 결과, 독립 검토자와 검토일.
- 실제 브라우저 375px 화면과 PDF·HTML 열림은 확인했습니다. 실물 휴대전화와 프린터의 5분 탁상훈련은 남아 있습니다.
- 공개 후보를 다시 생성한 뒤 전체 Git 이력·아티팩트·화면 이미지에서 가족 정보와 개인 재고가 없는지 최종 확인한다. 현재 자동 검사는 로컬 이력과 공개 파일에서 개인정보 형식 일치 항목을 찾지 못했고, 공개용 이미지는 가상 데이터만 사용하며 EXIF 위치 정보가 없다.
- 새 후보의 운영 HA **375px 화면**, 생수 L 편집 화면, 안내의 장기 준비 문구를 확인했다. 합성 재고의 0→2→4 L 채움과 200% CSS 확대 근사를 Chromium으로 검사했다. 실제 브라우저 200% 확대와 밝은·어두운 테마의 재검증 결과를 기록한다.

공개 후에는 `CHANGELOG.md`의 안전 문구 변경 내용을 읽고 종이판의 버전을 비교하여 재인쇄하세요.
