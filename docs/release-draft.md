# 0.1.0 공개 프리뷰 릴리스 초안

현재 상태는 **공개 보류**입니다. 콘텐츠 버전 `0.1.0-draft.3`을 검토 완료 버전으로 올리고 인쇄물을 다시 생성한 뒤 본문을 확정합니다.

## 제공 파일

- `custom_components/kr_survival_kit/` · HA 2026.11.0에서 시험한 로컬 재고 통합.
- `kr-survival-kit-a4.pdf` · 흑백 A4 행동 안내와 가족 기록지 두 쪽.
- `kr-survival-kit-offline.html` · 인터넷 없이 여는 단일 HTML.
- `dashboard.yaml` · Sections 대시보드 원시 설정.
- `kr-survival-kit-card.js` · 재고 카드 리소스. 통합 폴더에도 포함됩니다.

## 공개 전 채울 검증 기록

- 새 설치, P4에서 업데이트, 삭제, MQTT 단절 중 재고 조회·수정의 실제 결과.
- 생성 파일 해시와 HTML·PDF 버전 일치, 한글 글꼴, 두 쪽 잘림 및 필기 공간 확인.
- 2026년 행정안전부 안내와 문장별 대조 결과, 독립 검토자와 검토일.
- 실물 휴대전화와 프린터의 5분 탁상훈련 결과.
- 전체 Git 이력·릴리스 압축 파일·합성 화면의 개인 정보 검사 결과.

공개 후에는 `CHANGELOG.md`의 안전 문구 변경 내용을 읽고 종이판의 버전을 비교하여 재인쇄하세요.
