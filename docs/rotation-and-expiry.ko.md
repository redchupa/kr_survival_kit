# 구매 단위별 기한과 순환 사용

기한 관리 품목의 `expires_on`은 구매 단위마다 제품 포장에서 확인한 **소비기한·사용기한** 또는 사용자가 정한 교체 점검일이다. 제조일이나 입고일 자체를 넣지 않는다. 포장에 기한이 없거나 기한을 판단할 수 없으면 비워 둔다. 기한 관리 품목의 빈 날짜 수량은 사용 가능한 수량으로 자동 집계하지 않고 `확인 필요`로 표시한다. 기한이 지난 수량도 사용 가능한 수량에서 제외한다. 포장 상태와 보관 조건이 나쁘면 날짜가 남았더라도 사용 가능하다고 단정하지 않는다.

각 구매 단위의 `received_on`은 입고일이다. 품목별 `review_interval_days`는 기본 30일인 **재고 점검 주기**이며 관리자가 수정하거나 기본값으로 되돌릴 수 있다. 앱은 마지막 실사일(실사가 없으면 알려진 입고일)과 점검 주기로 다음 점검일·남은 날을 표시한다. 입고일+점검 주기는 소비기한이 아니고 물품을 자동 만료시키지 않는다. 기존 저장본에 입고일이 없으면 미상으로 남기며 임의 날짜를 채우지 않는다.

## 식품과 발열식량

식품에는 제품에 표시된 **소비기한**과 보관 조건을 확인한다. 식품안전나라에 따르면 소비기한은 표시된 보관 방법을 지켰을 때 안전하게 섭취할 수 있는 기한이다. 제조일, 유통기한, 품질유지기한은 서로 다른 표시다. 발열식량은 제품별 포장당 인분과 실제 소비기한을 구매 단위별로 기록한다. 평소 먹는 식품부터 순환 사용하고, 원본 사전조사 파일의 `20개` 같은 개인 가정 수치를 공개 권장량으로 사용하지 않는다.

## 생수의 날짜

[2026년 시행 「먹는샘물등의 기준과 규격 및 표시기준 고시」 제7조](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000283440)는 먹는샘물의 유통기한을 제조일로부터 6개월 이내로 정하고, 품질을 입증해 승인받은 제품은 최장 2년까지 연장할 수 있도록 한다. 이는 모든 브랜드의 포장 표시일이 동일하다는 뜻이 아니다. 구매 단위별 실제 표시 날짜를 확인해 입력한다. 제조일이나 입고일만 보고 앱이 소비기한을 자동 산출하지 않는다.

## 부탄캔

부탄캔의 **제조일은 소비기한이 아니다.** 한국가스안전공사 광주광역본부의 2026년 노후 캔 수거 안내는 제조일로부터 3년이 지난 캔과 찌그러짐·고온 노출 등이 있는 캔을 수거 대상으로 든다. 이는 그 지역본부의 수거 안내이며 모든 제품의 법정 소비기한을 뜻하지 않는다. 앱의 `교체 점검일`에는 제품 안내와 이 기준을 확인해 사용자가 정한 날짜를 기록한다. 캔 상태가 불량하면 날짜와 관계없이 사용하지 않고 지자체·한국가스안전공사 안내에 따라 안전하게 수거·폐기한다. 휴대용 버너는 밀폐 공간에서 사용하지 않고, 과대 불판·버너 겹치기·나란히 사용을 피하며 사용 후 캔을 분리한다.

- [한국가스안전공사: 휴대용 가스버너 안전수칙](https://www.kgs.or.kr/kgs/agc/board.do?searchBoardSn=102696)

## 재고 기록의 의미

`확인된 0개`는 재고가 실제로 없다는 확인 결과다. 미기록이나 실사하지 않은 수량은 `확인 필요`다. 여러 구매 단위가 있다면 각각의 기한을 따로 기록하고, 먼저 기한이 오는 물품부터 평소에 사용하거나 교체한다. 재고를 수정할 때 실사 확인을 선택하지 않으면 마지막 실사 날짜를 덮어쓰지 않고 확인 필요 상태로 둔다. 브로커나 인터넷이 없어도 로컬 재고 조회·수정은 가능하다.

생수는 화면에서 L(리터)로 입력·표시하지만 저장소와 HA action은 기존처럼 정수 ml를 사용한다. 예를 들어 `2 L`는 `2000 ml`, `1.25 L`는 `1250 ml`로 저장된다. 이미 저장된 `1 ml`도 `0.001 L`로 표시해 다시 저장할 때 손실되지 않아야 한다. 수량 상한은 기존의 항목당 `1,000,000,000 ml`이고, 물 저장소의 단위나 스키마를 바꾸지 않는다.
