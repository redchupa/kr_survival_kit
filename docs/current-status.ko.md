# 현재 작업 상태와 다음 단계

2026-11-17 기준. 이 문서는 오래된 P2~P5 이력 아래에 쌓인 기록보다 최신 상태를 우선 요약한다. 저장소 밖의 개인 사전조사와 운영 재고를 공개 자료에 넣지 않는다.

소스 프리뷰는 [GitHub 공개 저장소](https://github.com/redchupa/kr_survival_kit)의 `main`에 게시했다. 안내와 퀴즈는 `draft.12`이며 검토 완료 릴리스는 아니다.

## 제품 방향

- 평소 소비하는 물품을 순환하며 가구별 준비를 기록하는 Home Assistant 앱이다. 정전과 통신 장애에 대비한 A4 한 장과 오프라인 HTML을 제공한다.
- 현재 화면은 2D 단계다. 실사했고 가구 목표량을 채운 품목만 한 카드에 그림 하나씩 나타난다. 최대 데스크톱 10열이며 좁은 화면에서는 줄바꿈한다. 3D 창고는 후속 단계다.
- 미션과 준비 레벨은 기록 상태를 이해하도록 돕는다. 퀴즈는 공식 안내를 익히는 학습 기능이다. 어느 점수도 생존 확률을 뜻하지 않는다.

## 날짜의 의미

- `received_on`: 실제 입고일. 기존 기록에 없으면 미상으로 유지한다.
- `expires_on`: 구매 단위의 포장에서 확인한 소비·사용·유통기한 또는 사용자가 정한 교체 점검일. 해당 물품의 표시를 보고 직접 입력한다.
- `review_interval_days`: 품목별 재고 실사 주기. 기본 30일이며 1~3650일로 바꿀 수 있다. 이 값으로 계산한 다음 점검일은 소비기한이 아니다.
- 생수 일반 유통기한은 2026년 고시 기준 제조일부터 6개월 이내이며 승인 연장 제품은 최장 2년까지 가능하다. 입고일은 제조일이 아니므로 앱에서 입고일에 6개월을 더해 확정 기한으로 저장하지 않는다. [고시 제7조](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000283440&chrClsCd=010202)와 [기한 기록 안내](rotation-and-expiry.ko.md)를 참고한다.
- 수량이 부족하거나 기한 미상·경과·실사 지연이면 해당 품목의 완비 그림을 보여 주지 않는다. 3일치 가구 예시는 시작을 돕는 수치이며 모든 가구의 최종 목표가 아니다.

## 확인한 사항

- 후속 품질 개선: 퀴즈 조작 시 저장 전 재고 입력이 사라지는 경로를 수정했다. 다시 풀기 기능과 저장된 응답 검증을 추가했다. 안내 unittest 23개, 재고 pytest 13개, 카드 JS와 Chromium 검사가 통과했고 375px/CSS 200% 퀴즈 캡처를 검토했다. 이 후속 변경은 로컬 후보이며 운영 HA 재배포 검증은 별도로 필요하다.
- 격리 HA Core 2026.11.1에서 입고일·품목별 점검 주기의 신규 저장, 기존 v1 저장본 로드, 수정·삭제·재시작·동시 수정·저장 실패·권한 검사를 마쳤다. 운영 재고에는 테스트 값을 넣지 않았다.
- 공식 안내 8문항의 정답·오답 설명, 상황 ID·출처 ID, 안내와 퀴즈의 버전 일치를 자동 검사한다. 문구는 아직 사람 검토 상태 `draft`다.
- A4는 첫 5분의 **행동 점검**과 경보별 첫 행동을 한 면에 넣었다. 컬러와 흑백 렌더에서 번호·구역선이 구분되는지 확인했다. 실물 인쇄 검증은 별도로 기록해야 한다.
- 로컬 안내 관련 `unittest` 23개, 재고 `pytest` 13개, 카드 JS·Chromium 합성 화면, 오프라인 HTML·A4 검증, HACS 파일 배치 검사가 통과했다. 합성 재고 화면에서 0→완비→기한 경과→삭제 전환과 375px·200% 확대 근사를 확인했다.
- NRGNC 운영 HA의 **전용** 통합·카드·대시보드를 백업 후 `draft.12` 후보로 갱신했다. JS·PDF·HTML의 서버 SHA256이 로컬 출력물과 같고, 통합 재로드가 성공했다. 운영 재고 저장본 SHA256 `92e87cfe4e752dff53a38db21a57d60daeb1c06cc0fa0a4f39029817ad9d586a`는 갱신 전후 같다. 실제 재고를 시험용으로 저장하지 않았다.
- 인증된 운영 브라우저의 375px 화면에서 가로 넘침 없음(`clientWidth`=`scrollWidth`=365px), 미션 0/4와 빈 명부, 퀴즈 한글·오답 해설·정답·공식 출처, 생수 목표 L·입고일·표시 기한·점검 주기 입력, 상황 안내의 한국어 문구를 확인했다. 편집 화면은 저장하지 않고 취소했다.
- 전체 Git 이력과 공개 파일의 개인정보 형식 검사, HACS 파일 배치 검사가 통과했다. 새 커밋과 캡처를 추가한 뒤 재검사해야 한다.

## 다음 작업

1. 실제 물품의 구매 단위별 기한·입고일은 사용자가 직접 입력해야 한다. 제품군에 하나의 소비기한을 임의로 강제하지 않는다. 격리 HA에서 새 필드 저장·재시작은 검증했지만 **운영 HA의 실물 재고 변경 시험은 하지 않았다**.
2. 네이티브 200% 브라우저 확대와 밝은 테마, 실물 휴대전화·종이 인쇄물에서의 확인은 아직 수동 검증 대기다. Chromium의 CSS 200% 근사와 컬러·흑백 PDF 렌더 검토는 완료했다.
3. 안내·퀴즈 문구의 독립적인 사람 검토가 끝날 때까지 정식 안전 안내나 HACS 안정 릴리스라고 표시하지 않는다. 공개 GitHub에는 초안 프리뷰임을 명시한다.
4. 2D 사용성을 먼저 확인한 다음, 품목별 통일된 벡터 그림과 3D 창고 애니메이션을 별도 단계로 구현한다. 현재 아이콘은 품목별로 다르지만 일부는 운영 체제 이모지라 화풍이 일정하지 않다.

다른 모델의 작업 인계는 Git 저장소 **상위 폴더** `HANDOFF_FOR_NEXT_MODEL.md`에 있다. 해당 파일에는 개인 자료의 경계와 재현 명령이 있으며 공개 Git에는 포함되지 않는다.
